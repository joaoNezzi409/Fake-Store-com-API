# Fake Store API - React Native

Aplicativo desenvolvido em React Native utilizando a Fake Store API.

## Funcionalidades

- Listagem de produtos
- Busca de produtos pelo título
- Filtro por categoria
- Visualização dos detalhes do produto
- Controle de quantidade
- Adição de produtos ao carrinho
- Alteração da quantidade no carrinho
- Remoção de produtos
- Cálculo de subtotal, frete e total
- Tratamento de carregamento, erro e lista vazia

## API utilizada

Fake Store API:

https://fakestoreapi.com/

## Como executar o projeto 

- git clone https://github.com/joaoNezzi409/Trabalho-Fake-Store.git
- npm install
- npm start
